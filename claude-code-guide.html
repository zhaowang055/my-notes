Claude Code 完全指南

从入门到进阶，一本面向零基础用户的 Claude Code 使用手册。涵盖环境准备、核心概念、实战案例、进阶技巧，以及与 OpenClaw 的关系。

什么是 Claude Code？

💡 一句话理解：Claude Code 是一个住在你终端（命令行）里的 AI 编程助手。你用自然语言告诉它想做什么，它就能帮你读代码、写代码、运行命令、管理文件——就像一个随时在线的程序员搭档。

它能做什么？

能力举例
📖 阅读和理解代码"帮我解释一下这个项目的代码结构"
✏️ 编写和修改代码"帮我写一个 Python 快速排序函数"
🖥️ 执行终端命令"帮我运行 npm install"
🐛 调试和修复 Bug"这段代码报错了，帮我找原因并修复"
📁 管理文件"帮我在 src 目录下创建一个新的组件文件"
🔍 搜索代码库"帮我找到所有调用 getUserInfo 的地方"

它和 ChatGPT / 网页版 Claude 有什么区别？

对比项ChatGPT / 网页版 ClaudeClaude Code
运行环境浏览器里聊天你电脑的终端里
能否读你的代码不能，需要你手动粘贴能，直接读取你的项目文件
能否修改文件不能能，直接帮你创建和编辑文件
能否运行命令不能能，帮你在终端执行命令
适用场景通用问答、写小段代码真正的项目开发工作

0前置知识

📚 如果你从未接触过编程，这一章会帮你理解后面会反复出现的几个基本概念。已经有一定基础的同学可以跳过。

什么是终端（Terminal）/ 命令行？

你平时怎么操作电脑？ 点击图标、双击文件、右键菜单——这叫"图形界面"。终端是另一种操作电脑的方式：你输入一行文字命令，电脑执行后把结果显示出来。

举个例子：

  • 图形界面操作：打开文件管理器 → 找到文件夹 → 右键 → 删除
  • 终端操作：输入 rm -rf 文件夹名 → 回车 → 完成

为什么 Claude Code 要用终端？ 因为终端是最高效的"人机对话"方式。Claude Code 住在终端里，你在终端里和它用文字对话，它就能帮你操作电脑。

系统打开方式
Windows按 Win + X，选择"Windows PowerShell"或"终端"；或者在开始菜单搜索"PowerShell"
Mac按 Command + 空格，输入 Terminal，按回车
💡 小技巧：建议把终端固定到任务栏/Dock 栏上，后续你会经常用到它。

终端基础命令速查（5 个就够了）

命令含义例子
pwd我在哪？（显示当前路径）pwd → /Users/yourname
ls / dir这里有什么？（列出文件）ls → 显示当前目录文件列表
cd 文件夹名去别的地方（进入目录）cd Desktop → 进入桌面

🎯 练习一下：打开终端，依次执行 pwd → ls → cd Desktop → mkdir ai-tools → cd ai-tools。如果每一步都成功了，终端入门完成！

什么是目录/文件夹和根目录？

"目录"就是"文件夹"，两个词是同一个东西。根目录就是你项目文件夹的最顶层：

my-website/            ← 这就是项目根目录
├── src/               ← 源代码目录
│   ├── index.js
│   └── style.css
├── package.json       ← 项目配置文件
└── README.md          ← 项目说明文件

什么是 Node.js？什么是 npm？

Node.js 是一个让 JavaScript 代码能在电脑上运行的环境。Claude Code 是用 JavaScript 写的，所以需要 Node.js 才能运行。

npm 是 Node.js 的"应用商店"，用来安装各种工具。npm install xxx 就像在应用商店点"安装"。npm 随着 Node.js 一起安装，装了 Node.js 就自动有了 npm。

什么是项目依赖（Dependencies）？

依赖就是你的项目需要用到的"别人的代码"。 比如你做网站需要用到 React（别人写好的 UI 框架）。package.json 是项目的"购物清单"，记录了需要哪些依赖。npm install 就是按清单把所有依赖下载下来。

什么是 .md 文件？

.md 是 Markdown 文件，一种简单的排版语言，用纯文本就能写出带格式的文档。飞书、Notion 底层很多都是 Markdown。

1环境准备与安装

安装 Claude Code

Claude Code 提供了原生安装器，不需要安装 Node.js 也能用，一行命令搞定。

Mac 用户：

curl -fsSL https://claude.ai/install.sh | bash

Windows 用户（PowerShell）：

irm https://claude.ai/install.ps1 | iex

验证安装：

claude --version

看到版本号说明安装成功。

💡 不想用命令行安装？ 也可以在 VSCode 扩展商店搜索 "Claude Code" 安装，直接在编辑器里使用。

认证登录

方式一：API Key（推荐）

  1. 访问 console.anthropic.com，注册账号
  2. 在 API Keys 页面创建密钥（sk-ant- 开头）
  3. 在 Billing 页面添加付款方式，设置月度上限（如 $20）
  4. 在终端设置环境变量：
# Mac/Linux
export ANTHROPIC_API_KEY="sk-ant-你的密钥"

# Windows PowerShell
$env:ANTHROPIC_API_KEY="sk-ant-你的密钥"

方式二：Claude Pro/Max 订阅

直接在终端输入 claude，会弹出浏览器让你用 claude.ai 账号登录。

确认登录成功：

claude doctor
💰 费用参考：日常轻度使用，月费用大约 $5-$15。建议在 Anthropic Console 设置月度上限，防止意外超支。

启动

cd 你的项目目录    # 先进入项目文件夹
claude             # 启动

看到 > 提示符后就可以对话了。退出方式：输入 /exit 或按 Ctrl + C 两次。

5核心概念详解

Skill（技能）—— 给 Claude Code 装"技能包"

🎯 一句话理解：Skill 就是你预先写好的"操作手册"，告诉 Claude Code "遇到某类任务时，按这个步骤来做"。

Skill 本质上就是一个 .md 文件，用自然语言写清楚执行步骤。就像你写给同事的操作手册，只不过"同事"换成了 Claude Code。

两种 Skill 类型

类型说明触发方式
参考型Claude 需要时自动加载自动，不用管
工作流型你主动用 /命令 触发手动输入命令

工作流型示例（代码审查）：

# .claude/skills/review/SKILL.md
---
name: review
description: 代码审查流程
---
当用户要求审查代码时：
1. 检查语法错误
2. 检查潜在 Bug
3. 检查代码风格
4. 检查安全漏洞
5. 给出改进建议
💡 不知道怎么创建？ 直接让 Claude Code 帮你："帮我创建 .claude/skills/ 目录，并在里面创建一个 review.md 文件。" 它会自动完成。

Skills 生态资源

资源地址
官方 Skills 仓库github.com/anthropics/skills
Skills 市场skills.sh / skillsmp.com
ClawHub 社区clawhub.ai
OpenClaw Skills通过 openclaw plugins install 安装

MCP（模型上下文协议）—— 让 Claude Code 连接外部世界

🔌 一句话理解：MCP 就是一个"插头"，让 Claude Code 能连接飞书、GitHub、数据库等外部服务。

想象 Claude Code 是一个很聪明的人，但被关在一间屋子里（你的电脑终端）。MCP 就是给这个屋子装了很多扇窗户和门：

  • 通过"飞书窗户"读写飞书文档
  • 通过"GitHub 门"操作代码仓库
  • 通过"数据库窗户"查询数据

怎么配置？ 在配置文件中添加 MCP 服务器：

// ~/.claude/settings.json
{
  "mcpServers": {
    "feishu": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/feishu-mcp-server"],
      "env": {
        "FEISHU_APP_ID": "你的应用ID",
        "FEISHU_APP_SECRET": "你的应用密钥"
      }
    }
  }
}
⚠️ 注意：每个 MCP Server 会占用上下文空间。装太多会吃掉大量空间。用 /mcp 命令查看占用情况，按需启停。

CLAUDE.md（项目记忆文件）

📋 一句话理解：CLAUDE.md 就是你写给 Claude Code 的"项目说明书"，每次启动时它会自动阅读。

快速创建：在项目文件夹里启动 Claude Code 后，输入 /init，Claude 会自动扫描项目帮你生成。

写 CLAUDE.md 的核心原则

只写 Claude 无法自己推断出来的东西。

✅ 应该写的

  • 构建和测试命令
  • 代码规范中的特殊约定
  • 重要注意事项（用 IMPORTANT: 标记）

❌ 不应该写的

  • Claude 读代码就能知道的
  • 标准语言约定
  • 经常变化的信息
💡 检验标准：对每一行问自己——"删掉这行，Claude 会犯错吗？"如果不会，就删掉。臃肿的 CLAUDE.md 反而会让 Claude 忽略重要指令。

模块化规则

规范太多？用 .claude/rules/ 目录拆分：

.claude/
├── CLAUDE.md              # 主文件：核心规范
└── rules/
    ├── code-style.md      # 代码风格
    ├── testing.md          # 测试约定
    └── api-design.md       # API 设计规范

Memory（记忆系统）

🧠 一句话理解：Memory 是 Claude Code 的"笔记本"，把重要信息记下来，下次对话还记得。 
> 记住：我习惯用 4 空格缩进
> 记住：我更喜欢用 Tailwind CSS

Plan Mode（规划模式）

🗺️ 一句话理解：Plan Mode 让 Claude 先把"施工计划"给你看，你批准后才开始干活。

最佳工作流：探索 → 规划 → 执行

  1. 探索（按 Shift+Tab 进入 Plan Mode）：> 读一下 src/auth/ 目录，帮我理解登录流程
  2. 规划（还在 Plan Mode）：> 我想加上 Google OAuth 登录，给我一个详细计划
  3. 执行（再按 Shift+Tab 切回）：> 按照计划实现，写好后跑测试
  4. 提交：> 用描述性的 commit message 提交，然后开 PR

子代理（Sub-agents）

👥 一句话理解：子代理是 Claude 派出的"分身"，在独立的上下文中完成子任务，做完只把结论带回来。

上下文窗口是有限的。子代理在独立的上下文窗口里工作，就像让实习生去做调研，ta 看了 100 页材料，最后给你一页摘要。

> 帮我做一个代码库审计。用子代理分别检查：
> 1. 安全漏洞
> 2. 性能问题
> 3. 代码规范违规
> 最后汇总给我一份报告

Hooks（钩子）

⚙️ 一句话理解：Hook 是在特定节点强制自动执行的脚本。CLAUDE.md 是"建议"，Hook 是"必须执行"。
  • 每次编辑文件后自动跑 ESLint
  • 禁止 Claude 修改某些敏感文件
  • 每次提交前自动运行测试

6Claude Code 与 OpenClaw 的关系

🔌 很多人会混淆 Claude Code 和 OpenClaw。简单说：它们是两个独立的工具，解决不同的问题，但共享同一个 AI 大脑（Claude）。

三者的关系

Claude（AI 模型，真正"会思考"的部分）
  ├── Claude Code 调用它来工作
  └── OpenClaw 调用它来工作

一句话类比

工具类比
Claude公司里的 AI 专家（大脑）
Claude Code你去专家办公室找他——主动上门、用完离开
OpenClaw专家住在你家里——7×24 小时在线、主动帮你干活

核心区别

对比项Claude CodeOpenClaw
运行方式你主动打开，用完关掉常驻后台，7×24 在线
交互方式在终端里对话在飞书/WhatsApp 里发消息
核心优势深度理解代码库，专注项目开发连接消息平台，碎片化使用
官方产品✅ Anthropic 官方❌ 开源社区产品

常见误解

  • "必须先装 Claude Code 才能用 OpenClaw" → 不需要，完全独立安装。
  • "OpenClaw 自带 AI" → 不对，必须配置 LLM（如 Claude）才能工作。
  • "Claude Code 只能写代码" → 不对，PM 可以用它搭原型、写 PRD、分析数据。

OpenClaw 快速了解

🦞 一句话理解：OpenClaw 是一个开源的 AI Agent 平台，让 AI "住进"你每天用的飞书里，像发微信一样和 AI 对话。

它能做什么？

  • 主动提醒你（定时任务、日程提醒）
  • 记住你的偏好（持久记忆，跨对话保持上下文）
  • 操作你的电脑（读写文件、执行命令、浏览网页）
  • 连接多个平台（飞书、WhatsApp、Telegram 等同时在线）

安装（需要 Node.js 22+）：

npm install -g openclaw@latest
openclaw onboard --install-daemon

日常运维：

openclaw gateway status          # 查看状态
openclaw gateway restart         # 重启
openclaw logs --follow           # 查看日志
openclaw doctor                  # 诊断问题
⚠️ 安全要点：dmPolicy 保持 "pairing"，不要改 "open"；不要在存有敏感数据的电脑上安装；在 Anthropic Console 设好月度费用上限。

  • 善用 Plan Mode — 复杂任务先看计划再执行
  • 检查结果 — 输出不一定完美，养成检查的习惯
  • 用 CLAUDE.md 保存项目规范 — 避免每次重复说明

❌ 避免这样做

  • 不要一句话描述模糊需求（"帮我做个网站"）
  • 不要让它一次性修改太多不相关的文件
  • 不要忽略它的确认提示直接说"全部同意"
  • 不要在不清楚后果的情况下让它执行删除操作

10常见问题

Q: 完全不懂编程，能用 Claude Code 吗？

A: 能！核心交互方式是自然语言——你用中文告诉它想做什么就行。它会帮你写代码、执行命令、创建文件。你只需要检查结果是否符合预期。

Q: 使用 Claude Code 要花多少钱？

A: 用 /cost 查看费用。日常轻度使用月费约 $5-$15，建议设置月度上限。

Q: 对话太长、响应变慢怎么办？

A: 用 /compact 压缩历史，或 /clear 清除重新开始。复杂任务建议拆成多次短对话。

Q: Claude Code 写的代码有 Bug 怎么办？

A: 直接告诉它："运行时报错了，错误是 xxx，帮我修复。"

Q: 怎么让 Claude Code 记住我的偏好？

A: 两种方式：写在 CLAUDE.md 里（永久生效），或直接说"记住：xxx"。

Q: Claude Code 会不会把我电脑搞坏？

A: 它在执行任何操作前都会先告诉你并等你确认。仔细看操作说明再确认就不会有问题。

Q: Claude Code 和 OpenClaw 必须一起用吗？

A: 不需要，完全独立。你可以只用其中一个，装了两个也互不干扰。

Q: 这些工具安全吗？

A: Claude Code 是 Anthropic 官方产品，传输加密。但发给 AI 的内容会发送到服务器处理，请避免发送密码、银行卡号等敏感信息。
